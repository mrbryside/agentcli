# Bootstrap installer

Read this when changing the minimal starter generated by `init/install.sh`.

`init/install.sh` prompts through `/dev/tty` for the project folder and Go
module path. It does not request or persist provider credentials, accepts no
required positional arguments, and refuses to overwrite an existing target.

The installer detects `go env GOVERSION` for `go.mod` and falls back to
`1.26.3` when Go is unavailable. With Go installed, it resolves
`github.com/mrbryside/agentcli@latest` directly from Git and runs `go mod tidy`.
`AGENTCLI_VERSION` remains available for pinning or testing an unreleased
revision; the no-Go fallback version must track the current public API used by
the templates.

The generated project contains only:

```text
main.go
tool_glob.go
tool_read.go
.agentcli/MAIN.md
.agentcli/config.yaml
```

`MAIN.md` allowlists `glob` and `read`, and its complete Markdown body is
`You are chatbot.` The generated application registers those same two tools.
It has no generated skills, task agents, edit/report tools, guard models,
runtime logger, or observability exporter.

The generated config contains the permission mode, compaction settings, and
one OpenAI-compatible provider profile. It references `${API_KEY}` from the
process environment and intentionally contains no logging, observability, or
guardrail provider mapping. Keep it free of explanatory comments; setup
guidance belongs in documentation and installer output.

`init/templates/tool_read.go` and `init/templates/tool_glob.go` are downloaded
independently. Tests may replace their URLs with `AGENTCLI_TOOL_READ_URL` and
`AGENTCLI_TOOL_GLOB_URL`. Both templates use the public root facade and strict
`agentcli.DecodeArguments` decoding. `read` is bounded to UTF-8 project files;
`glob` is bounded to project-local matches and does not follow directory
symlinks. Both reject protected paths and declare low-risk filesystem-read
permission.

When changing the installer, run `sh -n init/install.sh`, execute it in a real
PTY against a temporary directory, inspect every generated file, then run
`go mod tidy` and `go test ./...` in the generated module.
