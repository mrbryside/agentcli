# Minimal Discord bot

This use case turns each Discord channel into one agentcli conversation. The
bot replies to direct messages and to guild messages that mention it.

There are two useful deployment shapes:

| Mode | Choose it when | Turn lifecycle |
| --- | --- | --- |
| **CLI / embedded process** | One Go executable can own Discord, tools, and the agent runtime. | Call `Agent.SendMessage`, drain its event subscription, then read `Run.Result`. |
| **REST API server** | Discord and the agent should deploy, scale, or restart independently. | `POST` a turn, then consume its returned SSE `events_url`. |

The embedded example is a normal command-line executable, not the Terminal UI.
Agentcli does not require or ship a separate daemon CLI. The API example adds
an explicit agent-server executable and keeps the Discord process as a small
HTTP client.

Configure any OpenAI-compatible provider:

```yaml title=".agentcli/config.yaml"
permission_mode: default

providers:
  primary:
    type: openai
    url: https://api.openai.com/v1
    api_key: ${OPENAI_API_KEY}
    request_timeout: 2m
```

Allow the main agent to use only the Discord delivery tool:

```markdown title=".agentcli/MAIN.md"
---
provider: primary
model: gpt-4.1-mini
tools:
  - report_discord
---

`report_discord` is the only user-visible response channel. Never emit a
normal assistant response. Finish the work first, then make exactly one
standalone `report_discord` call whose `message` contains the complete,
natural response to the Discord user. The message must be non-empty and no
longer than 2000 Unicode characters. Do not skip the report.
```

The `tools` allowlist makes the tool visible to the model; it does not install
the handler. Both deployment modes must also register the implementation with
`agentcli.WithTool(...)`.

Create the custom delivery tool:

```go title="internal/discordreply/report_discord.go"
package discordreply

import (
    "context"
    "encoding/json"
    "errors"
    "fmt"
    "strings"
    "unicode/utf8"

    "github.com/bwmarrin/discordgo"
    "github.com/mrbryside/agentcli"
)

const (
    sessionPrefix = "discord:channel:"
    maxRunes      = 2000
)

type messageSender interface {
    ChannelMessageSend(
        channelID string,
        content string,
        options ...discordgo.RequestOption,
    ) (*discordgo.Message, error)
}

type arguments struct {
    Message *string `json:"message"`
}

// SessionID keeps the Discord destination in the agent session identity.
// Reusing it preserves one conversation per Discord channel.
func SessionID(channelID string) string {
    return sessionPrefix + channelID
}

func NewTool(discord messageSender) agentcli.Tool {
    return agentcli.Tool{
        Definition: agentcli.ToolDefinition{
            Name: "report_discord",
            Description: "Deliver the complete final response to the Discord " +
                "channel. message is required and must contain at most 2000 " +
                "Unicode characters. This tool cannot be skipped.",
            InputSchema: agentcli.ObjectSchema(struct {
                Message agentcli.ToolParameter
            }{
                Message: agentcli.StringParameter(
                    "Complete user-facing Discord response.",
                ).Required().MinLength(1).MaxLength(maxRunes),
            }),
        },
        Handler: func(
            ctx context.Context,
            raw json.RawMessage,
        ) (json.RawMessage, error) {
            invocation, ok := agentcli.ToolInvocationFromContext(ctx)
            if !ok {
                return nil, errors.New("tool invocation context is required")
            }
            channelID, ok := strings.CutPrefix(
                invocation.SessionID,
                sessionPrefix,
            )
            if !ok || channelID == "" {
                return nil, fmt.Errorf(
                    "session %q is not a Discord channel session",
                    invocation.SessionID,
                )
            }

            var input arguments
            if err := agentcli.DecodeArguments(raw, &input); err != nil {
                return nil, err
            }
            if input.Message == nil ||
                strings.TrimSpace(*input.Message) == "" {
                return nil, errors.New("message is required")
            }
            if utf8.RuneCountInString(*input.Message) > maxRunes {
                return nil, errors.New(
                    "message exceeds Discord's 2000-character limit",
                )
            }
            if err := ctx.Err(); err != nil {
                return nil, err
            }
            if _, err := discord.ChannelMessageSend(
                channelID,
                *input.Message,
            ); err != nil {
                return nil, fmt.Errorf("send Discord response: %w", err)
            }
            return json.RawMessage(`{"status":"reported"}`), nil
        },
        Trigger:                            agentcli.EndResponseScope,
        EndTurnOnSuccess:                   true,
        CanonicalAssistantMessageParameter: "message",
    }
}
```

This follows the same delivery contract as the `report_discord` tool in the
reference Discord agent:

- `EndResponseScope` skips a tool-first call only on the initial human root
  turn, plus calls made while the scope is busy. A callback continuation may
  deliver on provider step one when it is the final active turn.
- `EndTurnOnSuccess` stops the model after final delivery, or yields an
  intermediate turn when callbacks still keep the response scope open.
- `CanonicalAssistantMessageParameter` stores the delivered `message` as the
  assistant response in conversation history.

An early call—including calling `report_discord` as the first tool—does not
send to Discord. With no callback or other active turn pending, it cannot end
the turn and ordinary work remains available. It returns:

```json
{
  "status": "skipped",
  "executed": false,
  "reason": "response_scope_not_ready_to_end",
  "instruction": "This call was skipped because an EndResponseScope tool cannot end the initial human root turn as its first provider action. Continue the remaining work and do not retry it in this provider round. On a later provider round, call it again only after the response is complete and the scope is quiescent."
}
```

The runtime does not guess whether the message sounds final. It rejects every
`report_discord` call emitted in the human root turn's first provider round, so
a tool-first progress message cannot end the turn. Callback continuations are
already past that first-action boundary and can deliver on provider step one.
A normal completion attempt can also open a restricted repair round. Early
arguments are never staged or delivered later.

Discord still enforces 2,000 Unicode characters per API message. If the
application permits a longer final response, split it deterministically at
paragraph/newline boundaries into Discord-safe chunks inside the delivery
sink. Do not return a length error to the model merely to ask it to shorten and
retry an already-final response.

The handler sends through Discord itself. The embedded bot and API client must
therefore wait for completion and handle errors, but must not send
`Run.Result.Content` to Discord a second time.

Both clients must create the agent session with
`discordreply.SessionID(event.ChannelID)`. The delivery handler deliberately
rejects any other session format because it would not have a trusted Discord
channel destination.

Set the two required secrets before running either mode:

```bash
export DISCORD_TOKEN='...'
export OPENAI_API_KEY='...'
go mod tidy
```

In API mode, provide `DISCORD_TOKEN` to both processes: `api-bot` uses it for
the Gateway connection, while `agent-server` uses it for the outbound
`report_discord` REST call.

The Discord application needs the **Message Content** privileged intent in the
Developer Portal. Invite it with permission to view channels, read message
history, and send messages.

```text
Discord Gateway → message handler → Agent.SendMessage → provider
                                            ↓
```

Create `cmd/embedded/main.go`:

```go title="cmd/embedded/main.go"
package main

import (
    "context"
    "errors"
    "log"
    "os"
    "os/signal"
    "strings"
    "sync"
    "syscall"

    "example.com/minimal-discord-bot/internal/discordreply"
    "github.com/bwmarrin/discordgo"
    "github.com/mrbryside/agentcli"
)

type bot struct {
    agent *agentcli.Agent

    mu   sync.Mutex
    busy map[string]bool
}

func main() {
    ctx, stop := signal.NotifyContext(
        context.Background(),
        os.Interrupt,
        syscall.SIGTERM,
    )
    defer stop()

    project, err := agentcli.LoadProject(".")
    if err != nil {
        log.Fatal(err)
    }
    discord, err := discordgo.New("Bot " + os.Getenv("DISCORD_TOKEN"))
    if err != nil {
        log.Fatal(err)
    }
    discord.Identify.Intents =
        discordgo.IntentGuildMessages |
        discordgo.IntentDirectMessages |
        discordgo.IntentMessageContent

    agent, err := agentcli.New(ctx,
        agentcli.WithProject(project),
        agentcli.WithNonInteractive(true),
        agentcli.WithTool(discordreply.NewTool(discord)),
    )
    if err != nil {
        log.Fatal(err)
    }
    defer agent.Close()

    app := &bot{agent: agent, busy: make(map[string]bool)}
    discord.AddHandler(app.onMessage)
    if err := discord.Open(); err != nil {
        log.Fatal(err)
    }
    defer discord.Close()

    log.Println("Discord bot is ready")
    <-ctx.Done()
}

func (b *bot) onMessage(
    session *discordgo.Session,
    event *discordgo.MessageCreate,
) {
    if event.Author == nil || event.Author.Bot ||
        !addressedToBot(session, event) {
        return
    }

    prompt := cleanPrompt(session, event.Content)
    if prompt == "" {
        return
    }
    conversation := conversationID(event)
    if !b.claim(conversation) {
        _, _ = session.ChannelMessageSend(
            event.ChannelID,
            "A response is already in progress for this channel.",
        )
        return
    }
    defer b.release(conversation)

    _ = session.ChannelTyping(event.ChannelID)
    run, subscription, err := b.agent.SendMessage(
        context.Background(),
        conversation,
        prompt,
    )
    if err != nil {
        b.sendError(session, event.ChannelID, err)
        return
    }

    // A live subscription must be drained. This is also where a richer bot
    // can render tool, reasoning, permission, and compaction progress.
    for range subscription.Events {
    }

    // report_discord has already delivered the canonical response. Reading the
    // result only confirms that the turn and Discord delivery both succeeded.
    if _, err := run.Result(); err != nil {
        b.sendError(session, event.ChannelID, err)
    }
}

func (b *bot) claim(id string) bool {
    b.mu.Lock()
    defer b.mu.Unlock()
    if b.busy[id] {
        return false
    }
    b.busy[id] = true
    return true
}

func (b *bot) release(id string) {
    b.mu.Lock()
    delete(b.busy, id)
    b.mu.Unlock()
}

func (b *bot) sendError(
    session *discordgo.Session,
    channelID string,
    err error,
) {
    if errors.Is(err, agentcli.ErrTurnInProgress) {
        _, _ = session.ChannelMessageSend(
            channelID,
            "A response is already in progress.",
        )
        return
    }
    log.Printf("agent turn failed: %v", err)
    _, _ = session.ChannelMessageSend(
        channelID,
        "Sorry, I could not complete that request.",
    )
}

func conversationID(event *discordgo.MessageCreate) string {
    return discordreply.SessionID(event.ChannelID)
}

func addressedToBot(
    session *discordgo.Session,
    event *discordgo.MessageCreate,
) bool {
    if event.GuildID == "" {
        return true
    }
    if session.State == nil || session.State.User == nil {
        return false
    }
    for _, mention := range event.Mentions {
        if mention != nil && mention.ID == session.State.User.ID {
            return true
        }
    }
    return false
}

func cleanPrompt(session *discordgo.Session, content string) string {
    if session.State == nil || session.State.User == nil {
        return strings.TrimSpace(content)
    }
    id := session.State.User.ID
    content = strings.ReplaceAll(content, "<@"+id+">", " ")
    content = strings.ReplaceAll(content, "<@!"+id+">", " ")
    return strings.Join(strings.Fields(content), " ")
}

```

Run the combined bot:

```bash
go run ./cmd/embedded
```

session. Different Discord channels still run concurrently.

This shape runs two processes:

```text
Discord Gateway → discord-api-bot → JSON + SSE → agent-server → provider
                                                       ↓
                                              report_discord → Discord REST
```

The server owns agent state, tools, permissions, subagents, and the per-session
turn queue. The Discord client translates inbound messages and watches SSE for
completion or failure; the registered `report_discord` tool sends successful
responses from the server process.

### Agent server

Create `cmd/agent-server/main.go`:

```go title="cmd/agent-server/main.go"
package main

import (
    "context"
    "log"
    "os"
    "os/signal"
    "syscall"

    "example.com/minimal-discord-bot/internal/discordreply"
    "github.com/bwmarrin/discordgo"
    "github.com/mrbryside/agentcli"
)

func main() {
    ctx, stop := signal.NotifyContext(
        context.Background(),
        os.Interrupt,
        syscall.SIGTERM,
    )
    defer stop()

    project, err := agentcli.LoadProject(".")
    if err != nil {
        log.Fatal(err)
    }
    discord, err := discordgo.New("Bot " + os.Getenv("DISCORD_TOKEN"))
    if err != nil {
        log.Fatal(err)
    }

    agent, err := agentcli.New(ctx,
        agentcli.WithProject(project),
        agentcli.WithNonInteractive(true),
        agentcli.WithTool(discordreply.NewTool(discord)),

        log.Fatal(err)
    }
```

### Discord API client

Create `cmd/api-bot/main.go`:

```go title="cmd/api-bot/main.go"
package main

import (
    "bufio"
    "bytes"
    "context"
    "encoding/json"
    "errors"
    "fmt"
    "io"
    "log"
    "net/http"
    "net/url"
    "os"
    "os/signal"
    "strings"
    "syscall"

    "example.com/minimal-discord-bot/internal/discordreply"
    "github.com/bwmarrin/discordgo"
)

type apiClient struct {
    baseURL string
    http    *http.Client
}

type startTurnResponse struct {
    SessionID string `json:"session_id"`
    TurnID    string `json:"turn_id"`
    Status    string `json:"status"`
    EventsURL string `json:"events_url"`
}

type turnEvent struct {
    Type   string `json:"type"`
    Error  string `json:"error"`
    Reason string `json:"reason"`
    Result *struct {
        Content string `json:"content"`
    } `json:"result"`
}

func main() {
    ctx, stop := signal.NotifyContext(
        context.Background(),
        os.Interrupt,
        syscall.SIGTERM,
    )
    defer stop()

    discord, err := discordgo.New("Bot " + os.Getenv("DISCORD_TOKEN"))
    if err != nil {
        log.Fatal(err)
    }
    discord.Identify.Intents =
        discordgo.IntentGuildMessages |
        discordgo.IntentDirectMessages |
        discordgo.IntentMessageContent

    client := &apiClient{
        baseURL: envOr("AGENTCLI_URL", "http://127.0.0.1:8080"),
        http:    &http.Client{},
    }
    discord.AddHandler(func(
        session *discordgo.Session,
        event *discordgo.MessageCreate,
    ) {
        if event.Author == nil || event.Author.Bot ||
            !addressedToBot(session, event) {
            return
        }
        prompt := cleanPrompt(session, event.Content)
        if prompt == "" {
            return
        }

        _ = session.ChannelTyping(event.ChannelID)
        _, err := client.runTurn(
            context.Background(),
            conversationID(event),
            prompt,
        )
        if err != nil {
            log.Printf("agent API turn failed: %v", err)
            _, _ = session.ChannelMessageSend(
                event.ChannelID,
                "Sorry, I could not complete that request.",
            )
            return
        }
        // report_discord runs inside agent-server and has already sent the
        // response. Do not send Result.Content again from this API client.
    })

    if err := discord.Open(); err != nil {
        log.Fatal(err)
    }
    defer discord.Close()
    log.Println("Discord API bot is ready")
    <-ctx.Done()
}

func (c *apiClient) runTurn(
    ctx context.Context,
    sessionID string,
    message string,
) (string, error) {
    body, err := json.Marshal(map[string]string{"message": message})
    if err != nil {
        return "", err
    }
    endpoint := c.baseURL + "/v1/sessions/" +
        url.PathEscape(sessionID) + "/turns"
    request, err := http.NewRequestWithContext(
        ctx,
        http.MethodPost,
        endpoint,
        bytes.NewReader(body),
    )
    if err != nil {
        return "", err
    }
    request.Header.Set("Content-Type", "application/json")

    response, err := c.http.Do(request)
    if err != nil {
        return "", err
    }
    defer response.Body.Close()
    if response.StatusCode != http.StatusCreated &&
        response.StatusCode != http.StatusAccepted {
        payload, _ := io.ReadAll(io.LimitReader(response.Body, 4096))
        return "", fmt.Errorf(
            "start turn: %s: %s",
            response.Status,
            strings.TrimSpace(string(payload)),
        )
    }

    var started startTurnResponse
    if err := json.NewDecoder(response.Body).Decode(&started); err != nil {
        return "", err
    }
    return c.waitForResult(ctx, started.EventsURL)
}

func (c *apiClient) waitForResult(
    ctx context.Context,
    eventsURL string,
) (string, error) {
    request, err := http.NewRequestWithContext(
        ctx,
        http.MethodGet,
        c.baseURL+eventsURL,
        nil,
    )
    if err != nil {
        return "", err
    }
    request.Header.Set("Accept", "text/event-stream")

    response, err := c.http.Do(request)
    if err != nil {
        return "", err
    }
    defer response.Body.Close()
    if response.StatusCode != http.StatusOK {
        payload, _ := io.ReadAll(io.LimitReader(response.Body, 4096))
        return "", fmt.Errorf(
            "stream turn: %s: %s",
            response.Status,
            strings.TrimSpace(string(payload)),
        )
    }

    scanner := bufio.NewScanner(response.Body)
    scanner.Buffer(make([]byte, 64*1024), 2*1024*1024)
    for scanner.Scan() {
        line := scanner.Text()
        if !strings.HasPrefix(line, "data:") {
            continue
        }
        var event turnEvent
        if err := json.Unmarshal(
            []byte(strings.TrimSpace(strings.TrimPrefix(line, "data:"))),
            &event,
        ); err != nil {
            return "", err
        }
        switch event.Type {
        case "run_completed":
            if event.Result == nil {
                return "", errors.New("run completed without a result")
            }
            return event.Result.Content, nil
        case "run_failed":
            return "", errors.New(event.Error)
        case "agent_interrupted":
            return "", fmt.Errorf("agent interrupted: %s", event.Reason)
        }
    }
    if err := scanner.Err(); err != nil {
        return "", err
    }
    return "", errors.New("event stream ended before a terminal event")
}

func envOr(name string, fallback string) string {
    if value := strings.TrimSpace(os.Getenv(name)); value != "" {
        return strings.TrimRight(value, "/")
    }
    return fallback
}

func conversationID(event *discordgo.MessageCreate) string {
    return discordreply.SessionID(event.ChannelID)
}

func addressedToBot(
    session *discordgo.Session,
    event *discordgo.MessageCreate,
) bool {
    if event.GuildID == "" {
        return true
    }
    if session.State == nil || session.State.User == nil {
        return false
    }
    for _, mention := range event.Mentions {
        if mention != nil && mention.ID == session.State.User.ID {
            return true
        }
    }
    return false
}

func cleanPrompt(session *discordgo.Session, content string) string {
    if session.State == nil || session.State.User == nil {
        return strings.TrimSpace(content)
    }
    id := session.State.User.ID
    content = strings.ReplaceAll(content, "<@"+id+">", " ")
    content = strings.ReplaceAll(content, "<@!"+id+">", " ")
    return strings.Join(strings.Fields(content), " ")
}
```

## What this minimal version leaves out

The examples intentionally implement only the direct-response path. Before
running a public bot, add the pieces required by your product:

- **Session ownership:** channel-scoped history means everyone in a channel
  shares context. Include the user ID for private per-user history, or use a
  thread ID for one conversation per thread.
- **SSE reconnect:** store the last event ID and reconnect with
  `Last-Event-ID`. Fetch the turn status if a stream ends unexpectedly.
- **Automatic subagent callbacks:** API clients should follow the
  [session-wide event stream](../api/sse-events.md#session-stream), not only one
  turn URL. Embedded clients should consume and continue
  `SubscribeSubagentCallbacks`.
- **Permissions and confirmations:** render requests from events and post
  explicit decisions. Never infer approval from a Discord reaction or timeout.
- **Progress:** use provider, tool, compaction, `pre_end_scope`, and
  `end_scope` events to drive typing and progress messages.
- **Routing and deduplication:** persist the Discord source message associated
  with each agent turn and make inbound Discord event IDs idempotent.
- **Security:** authenticate the REST API before binding it beyond loopback,
  limit request size and rate, and keep both Discord and provider tokens out of
  logs.

See [Build an application with the API](../examples/api-client-integration.md)
for the complete JSON/SSE lifecycle and
[Events](../api/sse-events.md) for every event payload.
